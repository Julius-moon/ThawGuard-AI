# 三分钟案例路线

这是一条可执行演示路线，不是已完成的人类理解度测试。

**0:00—0:25 / 首页**：研究对象是热融滑塌，方法是多波段卫星时序与公开S-CCD，当前输出是候选光谱变化与复核依据。30m是算法输入，10m是Sentinel形态参照。

**0:25—1:15 / 点击RTS1938**：白色十字是固定采样位置，边界是第三方事后清单。比较2019与2021，或切换2020-09-21/10-01。查看曲线；点击“回到首次检出前”“加入首次检出观测”，看到未形成断点与出现结构变化的区别。

**1:15—1:45 / 检查可解释核查**：算法先拟合季节与长期趋势，再寻找持续偏离。2020-09-29是回溯估计，2020-11-24是首次检出所需观测，不是地貌首次发生或预警提前量。清单一对多、0个核实负类，因此没有包装二分类准确率。

**1:45—2:30 / 地表与影响**：原2022边界18.28ha，2016—2022净增15.46ha；几何新增15.51ha是不同口径。WorldCover是分类背景，NDVI没有单调下降；最近记录路径9.77km、铁路24.23km，不能据此称威胁铁路或计算失效概率。

**2:30—3:00 / 输出**：记录实际核对的证据与疑问，在案例顶部或影响阶段导出判读说明。报告包含真实影像、原始观测、模型快照、来源和后验背景，交给研究者复核。当前价值是把可核查异常、空间范围和数据缺口放在一起；是否减少人工成本或提升时效仍需与人工基线实测。

应能回答的六个问题：

|问题|本例可支持的回答|
|---|---|
|哪里变了|北麓河RTS1938内固定30m采样像元，35.076075°N / 92.725643°E|
|何时发现|回溯估计2020-09-29，首次检出所需观测2020-11-24|
|算法依据|质量筛选后的多波段观测、季节/长期模型与持续偏离|
|能确认滑塌吗|历史清单与形态支持已有滑塌位置，断点具体过程与精确起始时间仍未独立确认|
|影响多大范围|只能报告注明口径的边界与分类范围，不能直接叫生态损失|
|有什么实用价值|定位值得复核的观测，比较时序与空间依据，输出可交接判读说明；不是未来预测或业务预警|
