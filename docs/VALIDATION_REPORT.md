## 未覆盖及发布条件

**第二台实体设备仍待验收。** Edge 与 Chrome 在同一台电脑运行，不能写成已完成双机。远程 GitHub 下载、macOS/Safari、用户单位策略、操作系统解压界面及真实人类三分钟理解度也未在此代测；当前 ZIP 由本地生成后解压验收。

第二台设备的最短清单：

1. 接收最终 Release ZIP，完整解压；断开网络，双击 `ThawGuard-AI/index.html`。
2. 六页各打开一次，确认地图、两期影像和光谱图可见。
3. 进入 1938，切换首次检出前/后，确认 0 → 1 处结构变化；切换影像和覆盖年份。
4. 在影响页从 1938 切到 1820、背景，再切回，确认没有串用专属数据。
5. 导出当前判读说明，在另一浏览器离线打开，检查编号、截止日期和图片。
6. 受本地文件策略限制时，在解压目录运行 README 的一条命令，并记录设备、系统、浏览器版本和结果。

这是外部设备的补测需求，不是新增研发、发布授权或购买服务的要求。源码包解压副本已重建成功，HTML 逐字节一致，副本 117 项科学完整性检查通过；借用既有 Node/Python 依赖，未冒充全新环境安装测试，详见 `qa/SOURCE_REBUILD_QA.json`；不能用本机双浏览器代替真实第二设备，也不能将工程通过视为专用模型精度或现场应用效益已获验证。
