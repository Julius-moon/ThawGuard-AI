# 90 天小规模验证计划

以下均为研究规划，尚未完成。首批拟验证用户为热融滑塌遥感科研判读人员；生态或工程机构的实际需求与合作关系仍须确认。

|时间|工作与产物|继续条件|
|---|---|---|
|1—30 天|冻结目标任务、授权范围与双人判读协议；补充阳性地貌和非 RTS 困难样本，记录时间区间、不确定标签、样本重叠及清单依赖；冻结空间分组和留出区域|没有可靠标签或存在泄漏，停止精度评估并补样|
|31—60 天|在相同独立留出条件下比较简单基线、公开 S-CCD 与获授权的场景化判别方法；回放只使用当时可获得信息，另计产品上架、计算和人工确认延迟|报告失败与不确定结果；没有增量不宣称方法优越或周尺度业务能力|
|61—90 天|与真实判读人员完成同任务对照，核对候选负担、每个确认事件的人工时间与证据交接质量；仅在有地面约束的范围开展影响研究|预先约定误报负担内取得可重复增量才扩大；否则收缩任务或调整方法|

建议起步采集至少 60 个双人确认阳性地貌、120 个经核实非 RTS 难例，覆盖云雪、水体、裸地扰动、道路施工、稀疏植被等。**这是起步规划，不是现有样本数量、功效保证或合作承诺。**

同一地貌及邻近空间块必须整体划入同一分组；有条件时冻结较早年份训练、较晚年份测试，并独立留出 RTS 1938 所在组。超参数和阈值仅在训练分组内选择，未来边界与人工结论不作为过去的输入。

事件层面报告查准、召回、PR-AUC、单位面积与时间窗的候选负担、发现延迟分布和计算消耗，并给出分组不确定区间。软件测试通过次数不进入科学准确率。设施和碳影响分别建立测量与过程验证，不由面积或距离直接推断。

公众理解度需单独测试：邀请未接触本项目的人按 README 三分钟路线操作，询问“识别了什么、何时知道、能证明什么、还缺什么”，保留回答和误解；目前没有此类受试者结果。
