# V7 final 定稿说明

日期 2026-10-18。范围依据用户本轮请求、`444.md` 及给定公开评审链接。对评审“有条件通过”的意见逐项核查，没有直接将主观评分当作验证结果。

本轮变更限于：

- 明示“10 m 形态参考，不是模型预测输出”；保留原点位真实影像。
- 用三句话说明公开 S-CCD、辅助判读与专用识别验证的关系；补充 S-CCD 原作者、实现作者与科研材料署名。
- 数据来源与产品链接提示需联网；公开软件版权声明随 HTML 保留。
- 导出文件名包含 RTS 编号和截至日期，正文补充输入假设、来源及不同统计单位不能比较精度的说明。
- 总览断点数显式按含 break 的段计数，避免混淆模型分段与结构断点；当前三个样本的最终显示数值仍为 0/1/0。
- 对照位置的影响页说明随点位变化；多源数据降级逻辑保留，另做往返切换验收。
- 以 `index.html` 为入口，新增下载、离线运行、源码复算、权利和测试说明，形成独立 Release 目录。

没有新训练模型，没有增加新的科学指标，没有全站重构，没有改变既有公开观测或 S-CCD 数值。旧 V7 候选 HTML 与旧 ZIP 保留；新终稿有独立文件名、路径和哈希。

PPT 和视频不在本轮改版范围内；不把第三方公开案例计算改写为团队原创科研进展。正式赛事材料是否齐全应独立核对。
